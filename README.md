# التمويل الإسلامي والمصارف الإسلامية: حزمة مذاكرة

## هيكل المستودع

| المجلد | ما فيه |
|---|---|
| `files/` | الملفات المرفقة: الدروس الأصلية (ZIP)، والمذكرة والملخص، وورقة معايير أيوفي |
| `files/src/` | مصادر HTML للمذكرة والملخص وسكربت توليد PDF (`node files/src/build.js`) |
| `assets/fonts/` | خط تجوال (Tajawal) المعتمد في كل الملفات والمواقع، مع رخصته OFL |
| `sites/` | المواقع والصفحات: `sites/cards/` موقع البطاقات |
| `games/` | الألعاب التعليمية (لا توجد لعبة لهذا المقرر بعد) |
| `index.html` | بوابة المقرر: روابط الأصل والمذكرة والملخص والبطاقات |

> ⚠️ المذكرة المدمجة والملخصات والبطاقات أُعدّت عبر نماذج الذكاء الاصطناعي ولم تتقدّم مراجعتها ولا تدقيقها؛ **حتى المذكرة دمجها الذكاء الاصطناعي** من شرائح الدروس. والتحقق منها مطلوب من الطالب، والمرجع عند أي اختلاف هو الدروس الأصلية في `files/الدروس-الأصلية.zip`.

| الملف | الوصف |
|---|---|
| [files/الدروس-الأصلية.zip](files/) | **الأصل:** شرائح الدروس العشرة (PDF) كما وصلت من المقرر، في مجلد مضغوط |
| [files/مذكرة-التمويل-الإسلامي-المدمجة.pdf](files/) | الدروس العشرة دمجها الذكاء الاصطناعي في مذكرة واحدة منسقة بخط تجوال (22 صفحة)، بألوان موفّرة للحبر |
| [files/ملخص-التمويل-الإسلامي.pdf](files/) | ملخص في 11 صفحة: خريطة ذهنية وجداول ومراحل وجدول جامع للصيغ، بألوان موفّرة للحبر |
| [files/معايير-أيوفي-للمقرر.pdf](files/) | ورقة معايير أيوفي الشرعية للدروس 3–7 (المعايير 8، 30، 9، 25، 10، 11، 61): البنود والضوابط وأجوبة تساؤلات المذكرة، وملحق ينبّه إلى أن المعايير 40 و46 و17 (الدرسان 9 و10) غير متضمنة ويحيل الطالب إلى مصادرها |
| [sites/cards/](sites/cards/index.html) | موقع بطاقات متدرّج: 121 بطاقة في 4 مستويات (13 الصورة الكبرى ← 26 المفاهيم ← 37 التفاصيل ← 45 الإتقان) بزر «تم» وحفظ التقدم ورابط التقدم |

## إعادة توليد المذكرة والملخص
عدّل `files/src/memo.html` أو `files/src/summary.html`، ثم شغّل من جذر المستودع:

```bash
node files/src/build.js
```

موقع البطاقات صفحة واحدة؛ افتح `sites/cards/index.html` في المتصفح، أو فعّل GitHub Pages على المستودع.
