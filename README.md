# التمويل الإسلامي والمصارف الإسلامية: حزمة مذاكرة

## هيكل المستودع

| المجلد | ما فيه |
|---|---|
| `files/` | الملفات المرفقة: المذكرة والملخص، وورقة معايير أيوفي |
| `sites/` | المواقع والصفحات: `sites/cards/` موقع البطاقات |
| `games/` | الألعاب التعليمية (لا توجد لعبة لهذا المقرر بعد) |
| `index.html` | بوابة المقرر: روابط المذكرة والملخص والبطاقات |

> ⚠️ الملخصات والبطاقات والألعاب أُعدّت عبر نماذج الذكاء الاصطناعي ولم تتقدّم مراجعتها ولا تدقيقها؛ والتحقق منها مطلوب من الطالب مع مطابقتها بالمذكرة المعتمدة.

| الملف | الوصف |
|---|---|
| [files/مذكرة-التمويل-الإسلامي-المدمجة.pdf](files/) | الدروس السبعة مدمجة في مذكرة واحدة منسقة بخط تجوال (18 صفحة) |
| [files/ملخص-التمويل-الإسلامي.pdf](files/) | ملخص في 8 صفحات: خرائط ذهنية وجداول ومراحل وجدول جامع للصيغ |
| [files/معايير-أيوفي-للمقرر.pdf](files/) | ورقة معايير أيوفي الشرعية للدروس (8، 30، 9، 25، 10، 11، 61): البنود والضوابط وأجوبة تساؤلات المذكرة |
| [sites/cards/](sites/cards/index.html) | موقع بطاقات متدرّج: 100 بطاقة في 4 مستويات (10 الصورة الكبرى ← 20 المفاهيم ← 30 التفاصيل ← 40 الإتقان) بزر «تم» وحفظ التقدم ورابط التقدم. مستوى الإتقان يجيب عن «تساؤلات» المذكرة من معايير أيوفي مع أرقام البنود |

4. الإيجار التمويلي (المنتهي بالتمليك)
